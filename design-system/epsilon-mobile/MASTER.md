# 입실론 모바일 디자인 시스템

## 방향

- 대상: 고등학생, 교사, 학원 관리자
- 사용 환경: 휴대폰 중심, 태블릿과 데스크톱 보조
- 성격: 신뢰 중심, 빠른 탐색, 높은 정보 밀도
- 방식: 기존 정보 구조와 기능 ID를 유지하는 점진적 리디자인
- 디자인 설정: variance 4, motion 3, density 7

## 핵심 토큰

- 기본 강조색: `#1d4ed8`
- 강한 강조색: `#1e40af`
- 약한 강조 배경: `#eff6ff`
- 앱 배경: `#f5f7fb`
- 기본 표면: `#ffffff`
- 기본 글자: `#0f172a`
- 보조 글자: `#475569`
- 테두리: `#dbe3ee`
- 카드 모서리: 16px
- 버튼과 입력 모서리: 12px
- 기본 간격: 4px와 8px 배수

## 타이포그래피

- 한글 UI: Noto Sans KR
- 점수와 숫자: Space Mono 또는 tabular figures
- 모바일 입력 글자: 최소 16px
- 본문 줄높이: 1.5 이상
- 작은 안내문도 10px 아래로 내리지 않는다.

## 모바일 규칙

- 주요 하단 메뉴는 홈, 입시, 테스트, 리포트, 더보기의 5개만 둔다.
- 자료실, 컬렉션, 앱 설치는 더보기 시트에서 제공한다.
- 모든 주요 터치 대상은 최소 44px이다.
- 고정 하단 메뉴와 시트는 `env(safe-area-inset-bottom)`을 반영한다.
- 가로 스크롤은 필터나 하위 탭처럼 의도된 영역에만 허용한다.
- 본문이 하단 메뉴 뒤에 가려지지 않도록 스크롤 여백을 확보한다.

## 상호작용과 접근성

- 키보드 포커스는 3px 링으로 표시한다.
- 아이콘 단독 버튼에는 `aria-label`을 둔다.
- 모달형 시트는 `role="dialog"`, `aria-modal="true"`, Escape 닫기를 지원한다.
- 애니메이션은 상태 전환에만 사용하며 `prefers-reduced-motion`에서 제거한다.
- 색상만으로 상태를 구분하지 않고 텍스트를 함께 표시한다.

## PWA

- `manifest.webmanifest`에서 standalone 실행과 192px, 512px, maskable 아이콘을 제공한다.
- `sw.js`는 동일 출처의 앱 셸만 캐시한다.
- 서버 데이터는 항상 네트워크를 사용하며 오래된 API 응답을 임의로 캐시하지 않는다.
- iOS는 Safari의 공유 메뉴, Android는 브라우저 설치 메뉴를 안내한다.
