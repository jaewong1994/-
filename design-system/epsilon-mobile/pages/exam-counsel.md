# 시험상담 페이지 — v65

## 목적

원장·강사가 본인이 만든 테스트의 응시 점수, 전체/반 등수, 메달을 학생별로 본다. 입시상담(정시·수시)과 화면을 분리한다.

## 권한

- 강사: `tests.created_by = 본인`인 테스트만 목록·등수·상담 리포트에 노출
- 원장: 전체 테스트 조회, 목록에 소유 강사 이름 표시
- 기존 `created_by`가 비어 있던 테스트는 민재웅T 계정에 귀속

## 레이아웃

- 입시상담과 같은 2열: 좌측 학생 목록 240–320px, 우측 리포트 워크스페이스
- 700px 이하: 세로 배치, 학생 목록은 2열 그리드
- 하단 주 메뉴는 홈·입시·테스트·리포트·더보기 5개를 유지하고, 입시상담·시험상담은 강사 전용 탭과 더보기 시트에 둔다

## 데이터 표현

- 평균·최고·최근 점수는 숫자 카드로 먼저 보여 준다
- 응시 2회 이상일 때만 점수/등수 선 그래프를 그린다. 등수 계열은 점선으로 점수 계열과 구분한다
- 회차별 성적 표를 항상 제공해 차트만으로 정보를 전달하지 않는다
- 등수 값이 없으면 `—`로 표시하고 빈 화면처럼 보이지 않게 한다
- 터치 영역 44px, 입력 16px, 포커스 링 유지. 내비게이션 아이콘은 Tabler 아웃라인을 쓰고 이모지를 쓰지 않는다
