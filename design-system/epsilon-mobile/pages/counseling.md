# 상담 페이지 — v61

## 목적

원장·강사가 태블릿에서 학생을 바꿔가며 6·9월 모의평가, 정시 가능 대학선, 수시 수능최저 조합, 예체능 실기전형을 한 흐름에서 상담한다. 학생은 공개된 상담 요약만 전략 탭에서 본다.

## 레이아웃

- 768px 이상: 상담 탭만 공통 본문 최대폭 제한을 해제하고, 좌측 학생 목록은 `240–320px` 범위에서 유동 조절하며 우측 상담 워크스페이스가 남은 폭을 모두 사용한다.
- 1500px 이상: 정시·수시 결과 카드를 2열로 전환해 넓은 화면의 빈 공간과 과도하게 긴 카드 폭을 줄인다.
- 700px 이하: 학생 목록과 워크스페이스를 세로 배치.
- 정보 우선순위: 학생/성적 → 목표 등급 → 정시/수시 결과 → 공개 메모.
- 터치 영역 44px 이상, 입력 높이 46px, 포인터·키보드 포커스 링 제공.

## 시각 언어

- 기존 cobalt 브랜드를 유지하고 navy는 상담 결과의 집중 영역에만 사용한다.
- 카드 반경 10–14px, 얕은 테두리와 최소 그림자로 밀도 높은 업무 화면을 만든다.
- 표준점수·차이는 Space Mono의 tabular figures를 사용한다.
- 상태는 색뿐 아니라 안정/적정/소신/상향 텍스트를 함께 표시한다.

## 신뢰도 표현

- 틀린 문항 원점수: 평가원 정답표의 실제 배점으로 계산.
- 표준점수: 공개 추정컷 기반이면 반드시 ‘추정 점수’ 표기.
- 외부 산출·성적표 입력: ‘확인 점수’로 구분.
- 복잡한 수시 최저 문장은 자동 판정하지 않고 ‘요강 확인’으로 표시.
- 예체능 결과는 실기 반영비율·종목의 최종 모집요강 확인 문구를 유지.

## 권한

- 상담 탭: `teacher`, `director`만 노출 및 접근.
- 상담 저장: 강사·원장만 가능.
- 학생 전략 탭: `published = true`인 본인 상담 요약만 조회.
